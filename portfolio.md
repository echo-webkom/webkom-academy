# Første prosjekt: portefølje

Dette prosjektet lærer deg å lage en enkel nettside hvor du kan vise frem prosjektene du jobber med, samt info om deg.

## Klone tutorial lokalt

For å få denne tutorialen lokalt på maskinen din, kjør:

```sh
git clone git@github.com:echo-webkom/webkom-academy.git
cd webkom-academy
```

## Sette opp nytt Next prosjekt

### Generere prosjekt

For å lage nytt NextJs prosjekt:

```sh
npx create-next-app@latest
```

Du blir først spurt om prosjekt navn, skriv inn `portfolio`.

Når du blir spurt om konfigurering, bruk default på alt (trykk enter).

### Installere dependencies

Når den er ferdig med å generere prosjektet, gå inn i mappen

```sh
cd portfolio
```

...og installer dependencies.

```sh
pnpm i
```

### Kjør!!

Kjør applikasjonen:

```sh
pnpm dev
```

Gå til `localhost:8080` i nettleseren for å se på din magiske nettside!
